This is an extension for the Addon [Shadowed Unit Frames](https://www.curseforge.com/wow/addons/shadowed-unit-frames-redux). It is required for this Addon to have any effect.

This will add a new indicator that can be configured in the SUF options. It allows to display a silver/gold dragon on the left or right side of the unit frame when the corresponding unit has rare/elite status. It is intended as a stronger visual aid in identifying special mobs by using graphics instead of the default text.
